# CRAFT Посты

Android-приложение (Flutter) для подготовки постов Instagram CRAFT SYSTEM:
фото из галереи → форма → AI (подпись + текст инфографики) → инфографика на главном фото,
логотип на остальных → превью → правка → «Сохранить всё» в галерею (альбом «CRAFT SYSTEM»).

## Что где
- `lib/models/post_draft.dart` — **набор полей формы** (`kInfographicFields`) и модель поста.
- `lib/services/image/template.dart` — **шаблон инфографики** и позиция логотипа (сейчас заглушка).
- `assets/logo.png` — логотип.
- `assets/overlays/*.png` — маски затемнения, снятые из Canva (`tool/overlays/build_masks.py`).
- `lib/services/ai/` — провайдеры AI (`stub`, `anthropic`, `openai`). Новый провайдер: класс `AiProvider` + строка в `ai_factory.dart`.
- В AI уходит только главное фото (≤1024 px, JPEG) и текст полей.
- Превью — 900 px; экспорт — полное разрешение, JPEG q92.

## Как устроен процесс
1. Выбор фото → форма → «Создать пост» (AI + превью). Пост сразу сохраняется
   в истории приложения (⏱ «Мои посты»): копии исходников, тексты, превью.
2. Превью: любое фото открывается на весь экран, увеличивается щипком
   или двойным тапом.
3. «Улучшить значки через AI» (в превью): AI смотрит на главное фото с
   инфографикой и рисует по 3 разных варианта каждого значка; можно дать
   пожелание («детальнее», «другие идеи», «короче подписи»). Выбранные
   значки сразу попадают в превью. Без ключа — варианты встроенных значков.
4. «Согласовать»: фото по одному на весь экран, начиная с главного.
   Свайп вправо — фото уходит на сохранение в галерею (фоном, в полном
   разрешении), свайп влево — остаётся. В конце можно пройти оставленные
   ещё раз или сохранить их.

## Сборка APK
Без установки: GitHub → Actions → «Build» → последний запуск → артефакт `craft-post-apk`.

Локально (нужны Flutter и Android SDK):
```
./tool/setup_android.sh      # создаёт android/ и добавляет разрешения
flutter pub get
flutter build apk --release  # build/app/outputs/flutter-apk/app-release.apk
```

## Веб-версия
Тот же код собирается для браузера (`./tool/setup_web.sh && flutter build web --no-web-resources-cdn`).
Отличия от телефона: готовые фото скачиваются в «Загрузки» браузера,
история постов хранится в IndexedDB браузера, ключ AI — в хранилище
браузера. Каждый пуш в `main` публикует её на GitHub Pages:
https://baboevazamatkz-create.github.io/Craft-post/ (workflow `build.yml`).

## Установка на телефон
1. Скопируйте `app-release.apk` на телефон.
2. Откройте файл, разрешите «Установку из неизвестных источников».
3. Запустите «CRAFT Посты» → ⚙ Настройки → выберите провайдера и вставьте API-ключ
   (хранится в защищённом хранилище устройства). «Заглушка» работает без ключа.
