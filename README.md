# CRAFT Посты

Android-приложение (Flutter) для подготовки постов Instagram CRAFT SYSTEM:
фото из галереи → форма → AI (подпись, тексты, варианты преимуществ) → выбор преимуществ →
AI рисует значки → выбор значков → инфографика на главном фото, логотип на остальных →
превью → правка → согласование и сохранение в галерею (альбом «CRAFT SYSTEM»).

## Что где
- `lib/models/post_draft.dart` — **набор полей формы** (`kInfographicFields`) и модель поста.
- `lib/services/image/template.dart` — **шаблон инфографики** и позиция логотипа (сейчас заглушка).
- `assets/logo.png` — логотип.
- `assets/overlays/*.png` — маски затемнения, снятые из Canva (`tool/overlays/build_masks.py`).
- `lib/services/ai/` — провайдеры AI (`anthropic`, `openai`; `stub` — только для тестов). Новый провайдер: класс `AiProvider` + строка в `ai_factory.dart`.
- При создании поста в AI уходит только главное фото (≤1024 px, JPEG) и текст полей,
  для значков — только подписи выбранных преимуществ и список имён библиотеки
  (без фото; список кэшируется на стороне Anthropic, повторные запросы дешёвые);
- Усилие рассуждений: тексты и подбор значков — low (быстро), плашки — medium,
  рисование значка — high (идёт фоном);
  кнопка «Плашки на остальные фото через AI» отправляет все фото поста (главное ≤768 px, остальные ≤1024 px).
- Превью — 900 px; экспорт — полное разрешение, JPEG q92.

## Как устроен процесс
1. Выбор фото → форма → «Создать пост»: AI пишет подпись и тексты и
   предлагает 8 вариантов преимуществ.
2. «Преимущества»: выбрать 3 (порядок — как нажимали), можно попросить
   ещё варианты, поправить подпись или добавить своё.
3. «Значки»: к каждому преимуществу AI сразу подбирает 2 значка из
   библиотеки Tabler (~3000 тонких контурных значков, MIT, `assets/icons`,
   сборка — `tool/icons/build_tabler.py`) — это секунды, — и фоном рисует
   свой (≈минута, можно не ждать). Выбрать по одному; «Ещё варианты» —
   новые, с пожеланием.
4. Превью. Пост сохраняется в истории приложения (⏱ «Мои посты»): копии
   исходников, тексты, превью. Любое фото открывается на весь экран.
   «Другие преимущества и значки» — вернуться к шагам 2–3.
5. «Плашки на остальные фото через AI» (в превью): AI смотрит на все фото
   поста и отмечает на не главных 1–3 интересных момента — инженерные
   решения и сложные места, а не очевидные предметы («Кабель в одну линию
   по лазеру», «Ни одного провода на виду»…). ✎ на фото — ручная
   правка: точку тянуть на деталь, плашку — куда удобно (длина и направление
   стрелки); у выбранной плашки — размер, длина полки, длина стрелки,
   направление (4 кнопки), «Авто», текст, удаление; «+ Плашка» — своя.
   «Убрать все плашки» — снять со всех фото разом (с «Вернуть»).
6. «Согласовать»: фото по одному на весь экран, начиная с главного.
   Свайп вправо — фото уходит на сохранение в галерею (фоном, в полном
   разрешении), свайп влево — остаётся. В конце можно пройти оставленные
   ещё раз или сохранить их.

## Сборка APK
APK собирается только по запросу, после согласования правок:
GitHub → Actions → «APK» → **Run workflow** (ветка `main`) → по готовности
артефакт `craft-post-apk` в этом запуске. Подпись постоянная (секреты
`ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD`), поэтому новая
версия ставится поверх старой с сохранением ключа AI и истории.

Каждая правка в `main` автоматически проходит проверку кода и тесты
и обновляет веб-версию (workflow «Build»).

Локально (нужны Flutter и Android SDK):
```
./tool/setup_android.sh      # создаёт android/ и добавляет разрешения
flutter pub get
flutter build apk --release  # build/app/outputs/flutter-apk/app-release.apk
```

## Веб-версия
Тот же код собирается для браузера (`./tool/setup_web.sh && flutter build web --no-web-resources-cdn`).
Отличия от телефона: готовые фото скачиваются в «Загрузки» браузера,
история постов хранится в IndexedDB браузера, ключ AI — в хранилище
браузера. Каждый пуш в `main` публикует её на GitHub Pages:
https://baboevazamatkz-create.github.io/Craft-post/ (workflow `build.yml`).

## Установка на телефон
1. Скопируйте `app-release.apk` на телефон.
2. Откройте файл, разрешите «Установку из неизвестных источников».
3. Запустите «CRAFT Посты» → ⚙ Настройки → выберите провайдера и вставьте API-ключ
   (хранится в защищённом хранилище устройства). Без ключа AI-шаги не работают —
   приложение так и напишет.
